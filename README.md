Welcome to **DORA TOOLS**, a premium magical gadget-inspired multi-tool SaaS platform designed with a pure white, sky-blue, glassmorphism, and 3D aesthetic.

Dora Tools houses **50 fully functional tools** across **10 magical categories**, engineered with **100% browser-based processing** (via WebAssembly, HTML5 Canvas 2D, and Web Crypto) for maximum privacy and instantaneous results with zero server file uploads.

## 🔒 Privacy & Architecture
- **100% Client-Side Execution**: All file processing happens locally in the user's browser sandbox.
- **Zero Server File Uploads**: PDF files, photos, spreadsheets, and private keys never leave the client device.
- **Database**: PostgreSQL with Prisma ORM (24 normalized models).
- **Payment Gateway**: Razorpay with server-side HMAC-SHA256 signature verification.
- **SEO Ready**: Dynamic `sitemap.xml`, `robots.txt`, Open Graph social previews, and structured metadata.
